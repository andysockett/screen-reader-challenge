Screen reader challenge

To simulate to the experience and potential frustration of a web user with a sight impairment, make your way through the following pages using only a screen reader.

The rules:

  • No inspecting pages
  • Disable captions
  • Your username: exclusiveHippo
  • Your password: blindtest

Setup:

  • Enable VoiceOver: command(cmd) + F5
  • VO = ctl + opt
  • Turn off/on caption panel: VO + fn + cmd + F10
    Should say "Hide Voiceover Visuals"
  • Turn off/on on screen captions/cursor: VO + fn + cmd + F11
    Should say "Hide Caption Window"

These steps are important to ensure you experience the challenge without any visual cues.

Voiceover basics:

  • VO = ctl + opt
  • Start reading: VO + A
  • Read next item: VO + →
  • Read previous item: VO + ←
  • Jump to top of page: VO + fn + ←
  • Click: VO + space ←
