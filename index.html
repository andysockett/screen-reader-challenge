Screen reader challenge

This is a short, deliberately difficult website-navigation exercise. Try completing the login and profile-update pages using a screen reader and your keyboard. It is designed to introduce some common accessibility barriers—not to reproduce the experience of living with sight loss.

New to screen readers? That is fine. You do not need prior experience. Set one up using the guide for your device below, try the few commands listed here, and take a break or stop whenever you like. You can also use the “Give up, show page” control on a challenge page to reveal its contents.

Before you start

  1. Use a computer with a keyboard and headphones or speakers. The built-in screen reader is enough; you do not need to buy or install anything on Mac, Windows, or many Linux computers.
  2. Turn on the screen reader using the instructions for your operating system below. If you have never used it, take a minute to listen to its introduction or tutorial first.
  3. Keep the screen reader running, open this page in a supported browser, and choose Start the challenge.
  4. Use the screen reader to explore and interact with each page. The pages intentionally contain confusing labels and controls. There is no timer and no penalty for getting stuck.

Set up your screen reader

Mac: VoiceOver

  1. Press Command + F5 to turn VoiceOver on or off. On some keyboards, use Fn + Command + F5. You can also turn it on in System Settings under Accessibility, then VoiceOver.
  2. For a first-time introduction, press VO + F8 to open VoiceOver Utility, or choose the VoiceOver tutorial from the VoiceOver menu. “VO” means holding Control + Option together.
  3. VoiceOver works with Safari and other browsers. If a command behaves differently, try Safari.
  4. Optional extra challenge: turn off your screen reader’s on-screen speech captions or caption panel before starting using VO + Fn + Command + F11 You can turn captions back on or stop at any time. This exercise cannot reproduce the experience of sight loss but will force you not to rely on visual cues.

Apple VoiceOver guide

Windows: Narrator (built in)

  1. Press Windows + Control + Enter to turn Narrator on or off. Or search Windows Settings for “Narrator” and switch it on.
  2. If this is your first time, follow Narrator’s start-up prompts to learn its basic controls.
  3. Narrator works with Microsoft Edge and other browsers. If you already use NVDA, it is also a popular free screen reader; download it from NV Access and follow its installation prompts.

Microsoft Narrator guide

Linux: Orca

  1. Open your desktop’s Settings and look under Accessibility for Screen Reader, or search for Orca in the applications menu. The exact steps depend on your Linux desktop.
  2. If Orca is not installed, use your distribution’s software installer to find and install “Orca screen reader,” then enable it in Accessibility settings.
  3. For help with setup and keyboard commands, see the Orca documentation.

Challenge rules and details

  • Please do not inspect the page visually, use developer tools, or look through the page source while attempting the challenge. The point is to try navigating with the screen reader.
  • The login page requires the username exclusive@hippodigital.co.uk and password blindtest.
  • The pages are intentionally inaccessible and can be frustrating. This is a learning exercise, not a test of you or of screen-reader users. Stop at any time, and remember that a short simulation cannot represent anyone’s real-world experience.
